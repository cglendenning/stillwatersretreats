📊 Understanding Your Dashboard Metrics:
  • Large Number = The metric value for your selected time period (e.g., "1,900" page views)
  • ↑ or ↓ Percentage = Trend compared to the previous period (e.g., "↑ 25%" means 25% increase)
  • "vs previous period (X)" = The actual value from the previous time period for comparison
  • Unique Visitors = Tracked by browser/user agent, so each visitor is counted once per device
  • Conversion Rate = (Checkouts ÷ Unique Visitors) × 100. A healthy rate is typically 2-5%.
